## 1. Executive Summary

This document defines the comprehensive evaluation criteria for selecting vendors for the Gujarat State CCTV Integration Project. The criteria are designed to ensure selection of technically competent, financially stable, and experienced vendors capable of delivering a secure, scalable, and interoperable solution.

## 5. Financial Evaluation Criteria

### 5.1 Financial Scorecard

| Category | Weight | Sub-categories |
|----------|--------|----------------|
| **Total Cost of Ownership** | **50%** | |
| Capital Expenditure | 25% | Hardware, software, implementation |
| Operational Expenditure | 15% | AMC, support, licenses |
| Hidden Costs | 10% | Customization, training, data migration |
| **Payment Terms** | **20%** | |
| Payment Schedule | 10% | Milestone-based payments |
| Payment Flexibility | 10% | Government budget cycle alignment |
| **Financial Stability** | **15%** | |
| Company Financials | 8% | Profitability, liquidity |
| Bank Guarantees | 7% | Performance, financial |
| **Cost Optimization** | **15%** | |
| Volume Discounts | 5% | Multi-year, bulk pricing |
| Cost Reduction Proposals | 5% | Efficiency suggestions |
| Value Engineering | 5% | Alternative cost-effective solutions |

### 5.2 Detailed Financial Evaluation

#### 5.2.1 Capital Expenditure (CapEx)

| Item | Evaluation Criteria | Max Points |
|------|---------------------|------------|
| Hardware Costs | Competitive pricing, quality | 10 |
| Software Licenses | Perpetual vs subscription | 10 |
| Implementation Cost | realistic estimation | 8 |
| Customization Cost | Scope clarity | 5 |
| Data Migration Cost | Existing data handling | 4 |
| Travel & Logistics | On-site deployment | 3 |

#### 5.2.2 Operational Expenditure (OpEx)

| Item | Evaluation Criteria | Max Points |
|------|---------------------|------------|
| Annual Maintenance | AMC cost, SLA coverage | 8 |
| Support Costs | 24/7 support, response time | 6 |
| License Renewals | Annual fees, escalation clause | 4 |
| Infrastructure Costs | Cloud hosting, bandwidth | 4 |
| Power & Cooling | Energy efficiency | 3 |

#### 5.2.3 Hidden Costs

| Item | Evaluation Criteria | Max Points |
|------|---------------------|------------|
| Additional Modules | Future feature costs | 5 |
| User Licenses | Per-user pricing | 4 |
| Training Costs | Beyond standard scope | 3 |
| Integration Costs | Third-party connections | 3 |
| Performance Tuning | Optimization services | 2 |

### 5.3 Financial Scoring Formula

```
Financial Score = (CapEx Score × 0.50) + (OpEx Score × 0.30) + (Hidden Cost Score × 0.20)

Where:
- CapEx Score = (Actual Lowest Bid / Vendor Bid) × 25
- OpEx Score = (Actual Lowest Annual Cost / Vendor Annual Cost) × 15
- Hidden Cost Score = (Actual Lowest Hidden Cost / Vendor Hidden Cost) × 10
```

## 12. Award Criteria

### 12.1 Selection Method

| Method | Applicability |
|--------|---------------|
| **Quality & Cost Based Selection (QCBS)** | Primary method |
| **Least Cost Selection** | If technical scores equal |
| **Best Value Selection** | If innovation is key |

### 12.2 Final Scoring Formula

```
Total Score = (Technical Score × 0.60) + (Financial Score × 0.30) + (Experience Score × 0.10)

Where:
- Technical Score = Sum of all technical parameters
- Financial Score = Based on TCO analysis
- Experience Score = Based on past performance & references
```

### 12.3 Award Decision

| Scenario | Decision |
|----------|----------|
| Single Vendor | Highest total score wins |
| Multiple Vendors | L1 (Lowest bidder) among qualified |
| Tie | Technical score breaks tie |
| Dispute | Committee vote (majority) |
